TUI picker

Key Action
Type Fuzzy search sessions and windows.
<C-j> Move down to the next selectable row.
<C-k> Move up to the previous selectable row.
Enter Restore the selected session or window.
Esc, <C-c>, <C-q> Cancel and close the picker.
<C-d> Delete window under cursor.
<Alt-d> Delete session that have window under cursor. Confirming via typing "y"
<C-r> Rename window under cursor.
<Alt-r> Rename session that have window under cursor
<C-n> Create new window in session under cursor. Enter window name.
<Alt-n> Create new session. Enter session name.
<Alt-w> Wakeup: Restore a saved session that is not currently running.
<Alt-s> Sleep: Save session state and close a running session.
