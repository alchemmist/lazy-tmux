Save your tmux sessions, then use the interactive picker to restore just the sessions or windows you need. Snapshots preserve pane layouts, running commands, and optional scrollback history.

![lazy-tmux demo — save, kill-server, and restore via the picker](./docs/public/assets/demo.gif)

For installation, usage, and the full CLI reference, see [lazy-tmux.xyz](https://lazy-tmux.xyz).
